# CEH Coursework

An archive of Python coursework covering browser automation and the security risks of file encryption. It contains two Selenium-based browser exercises and a separate Tkinter demonstration.

## Publication status

Keep this archive private while reviewing the account credentials in Git history, bundled executables, and the file-encryption demonstration. Treat the demonstration and its bundled samples as untrusted material.

The browser exercises read credentials from the local environment. The IMDb exercise uses `IMDB_EMAIL` and `IMDB_PASSWORD`. The Instagram exercise uses `INSTAGRAM_USERNAME` and `INSTAGRAM_PASSWORD`.
